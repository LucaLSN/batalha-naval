
# Batalha Naval em Python

Projeto acadêmico desenvolvido em Python para aplicar conceitos fundamentais de programação e Programação Orientada a Objetos (POO) por meio da implementação de um jogo de Batalha Naval.

## Sobre o projeto

O projeto consiste no desenvolvimento de um jogo de Batalha Naval em que o jogador posiciona embarcações em um tabuleiro e realiza disparos a partir de coordenadas informadas pelo usuário.

A aplicação utiliza classes, métodos e estruturas de dados para organizar a lógica do jogo e gerenciar as interações do jogador.

## Objetivos de aprendizagem

- Aplicar conceitos de Programação Orientada a Objetos.
- Compreender a criação e a instanciação de classes.
- Trabalhar com atributos, métodos, construtores (`__init__`) e o parâmetro `self`.
- Manipular listas e dicionários.
- Implementar regras de posicionamento de embarcações.
- Desenvolver a lógica de conversão de coordenadas e registro de disparos.

## Tecnologias utilizadas

- Python 3
- Programação Orientada a Objetos (POO)
- Listas e dicionários
- Estruturas condicionais e de repetição
- Entrada e saída de dados pelo terminal

## Funcionalidades

- Representação do tabuleiro por meio de uma estrutura bidimensional.
- Posicionamento de embarcações nas orientações horizontal e vertical.
- Conversão das coordenadas informadas pelo jogador em índices utilizados pelo Python.
- Registro de disparos no tabuleiro.
- Exibição do estado do tabuleiro no terminal.
- Validação de posições, conforme as regras implementadas.

## Conceitos aplicados

**Classes e objetos:** organização das entidades e responsabilidades do jogo.

**Método construtor (`__init__`):** inicialização dos atributos dos objetos.

**Atributos e métodos:** armazenamento de informações e implementação das ações do jogo.

**Estruturas condicionais:** verificação das condições de posicionamento e das regras do jogo.

**Estruturas de repetição:** processamento das posições e células do tabuleiro.

**Listas e dicionários:** representação da grade e conversão das letras das colunas em índices numéricos.

## Como executar

### Pré-requisitos

- Python 3 instalado.
- Git instalado, caso deseje clonar o repositório.

### Instalação

Clone o repositório:

```bash
git clone URL_DO_REPOSITORIO
```

Acesse a pasta do projeto:

```bash
cd NOME_DO_REPOSITORIO
```

Execute o arquivo principal:

```bash
python3 main.py
```

> Substitua `main.py` pelo nome do arquivo principal do projeto, caso seja diferente.
